# Custodia

Inventario y préstamo de equipo: qué tiene la empresa, quién lo tiene, desde cuándo y con qué evidencia. Cada entrega sale con su carta de resguardo firmada y un equipo dado de baja que todavía sirve se postula a [El Trueque](https://github.com/ReyDavidAG/trueque).

Parte del ecosistema **[Chispa](https://github.com/ReyDavidAG/chispa) · El Trueque · Custodia**, que comparte base de datos y personas.

- `propuesta/` · prototipo navegable (`python3 -m http.server 5184`).
- `supabase/` · esquema `custodia`, bucket de evidencias, semilla y prueba (`cd supabase/tests && npm install --ignore-scripts && npm run check`).
- `docs/database.md` · por qué cada tabla.
- `plan.md` y `state.md` · qué sigue y dónde vamos.

Propuesta personal con datos de ejemplo; no es un sistema oficial.
